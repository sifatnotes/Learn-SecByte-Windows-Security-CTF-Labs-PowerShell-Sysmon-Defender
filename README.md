# Windows Security, PowerShell & Sysmon CTF Labs

A curated index of [Learn SecByte cybersecurity labs](https://learn.secbyte.org/ctf/) covering Windows administration, PowerShell defense, endpoint protection, event log investigation, and security monitoring.

This repository is designed for cybersecurity students, SOC analysts, blue-team practitioners, Windows administrators, and security learners looking for hands-on exercises.

## Introduction

Windows security monitoring involves understanding system configuration, reviewing event data, investigating suspicious activity, and validating defensive controls. These labs provide starting points for exploring Windows security tools and operational concepts in authorized environments.

Use this repository to navigate the exercises, organize your learning, and document investigation techniques.

## Learning Path

1. Begin with Windows administration and task scheduling.
2. Explore WMI and WinRM in the provided lab environments.
3. Study PowerShell and Group Policy security concepts.
4. Review Defender and Windows Security Center exercises.
5. Practice examining Sysmon events and log data.
6. Explore the Hayabusa lab and document your investigation process.

## How to Use the Labs

1. Open each exercise using its direct link.
2. Read the instructions and confirm the permitted testing scope.
3. Complete the activities in the designated environment.
4. Record relevant commands, events, findings, and explanations.
5. Identify defensive improvements and revisit unfamiliar concepts.
